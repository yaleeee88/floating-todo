# 悬浮待办 · 时间线版

一个纯本地、低占用、始终置顶的桌面待办小组件。基于
[BUG-gao/floating-todo](https://github.com/BUG-gao/floating-todo) 的 Tauri 2
架构定制，支持 Windows 与 macOS。

## 本版本的重点

- 待办可设为单次、每天、工作日或自定义星期；重复待办按日期独立记录完成、子待办与提醒状态。
- 日期使用具体日期作为单次截止日或重复计划的开始日期；时间可选择“不设时间 / 时间点 / 时间段”。
- 未完成待办自动按截止日期、时间从近到远排列，已完成事项自动沉底。
- 折叠状态直接显示完整日期、星期、时间以及“剩余 / 逾期”天数。
- 点击任意待办可展开描述、链接和多条可独立勾选的子待办，并可继续编辑或删除。
- 支持“阶段目标”：目标始终只占一行，展开后显示当天需要完成的重复行动。
- 重复行动支持每天、工作日和自定义星期，只保存规则与完成记录，不预生成未来事项。
- 不同阶段目标当天需要执行的内容会汇总到首页“今日行动”，可直接勾选并按时间排序。
- 点击“新建”可选择普通待办或阶段目标；目标卡显示今日进度、本周行动与剩余天数。
- 普通待办和重复行动都支持时间点或同日时间段，并在时间点或时间段开始时提醒。
- 采用 macOS 原生提醒事项风格：系统材质、连续分组列表、系统蓝和语义状态色。
- 窗口拉宽到 720px 以上时仍保持“今日 → 最近 → 地平线 → 目标”的纵向顺序，并在模块内部自动分栏、放大字号。
- 阶段目标预览会随窗口宽度增加：宽屏最多显示 4 个，超宽预览最多显示 6 个，其余目标可一键进入完整清单。
- 深浅主题统一使用系统字体层级与克制的蓝、青强调色；日期和统计回归中性色，兼顾辨识度与长时间阅读舒适度。
- 首次运行自动启用开机启动；登录电脑后小组件会直接显示在桌面。
- 默认始终置顶、不占任务栏，并提供托盘、鼠标穿透、透明度和深浅主题设置。
- 数据只保存在本机 `localStorage`，支持 JSON 导入与导出。
- 已完成历史不会被删除；默认只渲染最近 16 条，需要时可展开更早记录，以控制长期运行的界面内存。
- 自动迁移原版 v0.3.x 的“今天 / 明天 / 后天”和“每天”待办数据。

## 使用

点击“新建”选择普通待办或阶段目标。普通待办可以填写重复日期、开始日期、时间、细节和子待办；
阶段目标可以设置目标日期，并添加多条每天、工作日或自定义星期执行的重复行动。
点击列表中的事项即可展开详情。

全局快捷键：

- Windows：`Ctrl + Shift + Space`
- macOS：`Command + Shift + Space`

窗口可拖动、缩放，并会在重启后恢复上次的尺寸与屏幕位置。开启鼠标穿透后，如需恢复交互，请在系统托盘菜单中选择
“切换鼠标穿透”。开机启动与始终置顶都可在设置中关闭。

## 本地开发

需要 Node.js 18+、Rust，以及对应平台的 Tauri 系统依赖。

```bash
npm install
npm run dev
```

构建安装包：

```bash
npm run build
```

Windows 构建产物位于 `src-tauri/target/release/bundle/nsis/`，macOS 构建产物位于
`src-tauri/target/release/bundle/dmg/`。

## 技术说明

- Tauri 2（Rust 后端 + 系统 WebView）
- 原生 HTML / CSS / JavaScript，无前端框架运行时
- 单个每分钟定时器负责刷新相对日期和检查到点提醒
- 本地持久化，无账户、无网络同步、无广告

原始项目及作者信息请见 [BUG-gao/floating-todo](https://github.com/BUG-gao/floating-todo)。
